# DNC Dashboard de Vendas

Bem-vindo ao **DNC Dashboard de Vendas**, um projeto para monitoramento e visualização de vendas utilizando uma interface moderna e responsiva.

## Visão Geral

Este projeto foi desenvolvido com o objetivo de fornecer uma ferramenta de análise de vendas. Ele utiliza fontes modernas, um layout minimalista e é desenvolvido com **TypeScript** para maior escalabilidade e robustez.

## Estrutura do Projeto

- **HTML**
  - Um arquivo principal `index.html` contendo a estrutura básica da página.
- **TypeScript**
  - Arquivo principal: `main.tsx` que gerencia a aplicação.
- **CSS**
  - Estilização importada diretamente do Google Fonts.

## Tecnologias Utilizadas

- **HTML5**
- **TypeScript**
- **React** (ou outro framework SPA, caso seja utilizado no `main.tsx`)
- **Google Fonts** para tipografia moderna.
- **Módulos ECMAScript** para melhor organização do código.

## Configuração

1. **Pré-requisitos:**
   - Node.js (v16 ou superior)
   - Gerenciador de pacotes (npm ou yarn) rules
